# Language-Learning API: Name Shortlist (first-pass research)

Date: 2026-09-25
Task: find a one-word product name for the planned "Duolingo inside Muse" language-learning API (sibling of Phos and Trophe). Research only. No domains registered, nothing purchased, no repos created, no development started.

## Recommendation

**Epea**

If Jeremiah approves in one word: Epea.

## Final shortlist of 3

### 1. Epea (recommended)

- Root: Greek ἔπεα, the plural of ἔπος (epos), meaning "words" - the classic Homeric formula "winged words" (epea pteroenta) is built on it.
- Fit: noun like Phos (light) and Trophe (nourishment); "words" is the core unit of a language-learning API. Pronounced eh-PEH-ah; spelling is phonetic.
- Product/app screen: no language-learning app, educational product, or API found under this name.
- GitHub exact-name screen: only stale dev repos - rgnter/epea_cpp (Edupage payload encryption, last touched ~2021) and epea/python-arduino-command-api (dead). Neither is a product or in the language lane.
- USPTO first-pass: no live word mark "EPEA" found in software, SaaS, API, or education goods/services classes.
- Adjacency notes: EPEA GmbH (part of Drees and Sommer) trades as "EPEA" in circular-economy/sustainability consulting, with marks like "Circularity Passport" in classes 009/035/042 - a different lane, no language or education use. "EPEA" is also a PCT patent-office acronym (International Preliminary Examining Authority) and the name of a search algorithm (EPEA*) and a metabolomics algorithm (ePEA) - all specialist jargon, not consumer products.
- .com: no live site found at epea.com. Registration status could not be confirmed with the tools available here - verify with a registrar before committing.

### 2. Akoe

- Root: Greek ἀκοή (Strong's G189), meaning "hearing" - the sense of hearing, the ear, what is heard. NT word (Romans 10:17 "faith comes by hearing"), matching the Phos/Trophe family.
- Product/app screen: collision found - akoe.ai is an active transcription, speaker-separation, dictation, translation, and subtitling service operated by TOOLBOX 21 (Kavala, Greece). Speech and translation tooling is adjacent to a language-learning API that plans listening and translation exercises.
- GitHub screen: sligodave/akoe (a stale 2012 script dump, "All Kinds of Everything"), an "AkoeNet" communication-platform project, and a portfolio project write-up. No language product, but the name is in use in comms software.
- USPTO first-pass: Serial 97210391 for "AKOE" (mood-enhancing supplements, class 005) is ABANDONED (May 2023). No live US mark in software/education found. Note: "AKOE EDUCACIO" is a registered mark in Spain (2006, class 41 education) held by Akoe Educacio Cooperativa Valenciana - a real education-lane collision outside the US.
- .com: no live site found at akoe.com. Registration status unconfirmed.
- Verdict: strong meaning and family fit, but the akoe.ai speech/translation service and the Spanish education cooperative materially burden it. Runner-up.

### 3. Semaino

- Root: Greek σημαίνω (Strong's G4591), "to signify, indicate, make known" - from σῆμα (sign, mark). Beautiful for language learning: the API makes meaning known. Pronounced say-MAI-no.
- Product/app screen: collision found - semaino Technologies GmbH (Germany) sells data-format/PIM software (ecatDESIGNER). B2B data software, not education, but an active software company on the name.
- GitHub screen: a "semaino" crate ships inside forkwright/akroasis (an active RF-signals/security toolkit, updated September 2026) - far lane, but active open-source use of the name.
- USPTO first-pass: no live US mark surfaced under this name.
- Structural note: it is a verb ("I signify"), breaking the noun pattern of Phos/Trophe/Epea.
- Verdict: meaning is excellent and the lane is far from language learning, but the German software company plus the verb form keep it third.

## Other candidates considered (with screening)

- **Mathema** - Greek μάθημα, "lesson." Burdened: reads as "math" in English; MATHEMA-GmbH is an active German AI company; "MATHEMIC" is a live EU mark held by MATHEMA covering education, translation, and software services; MatMot EU mark also held by MATHEMA. Too heavy to recommend.
- **Dictum** - Latin "a saying" (from dico, "I speak"). Eliminated: five active exact-name GitHub repos, nearly all voice-dictation/speech-to-text apps (nikoro/dictum, streetwallhacker/dictum, vkandil/dictum, thomasbunch/dictum, rtf22/dictum) plus discover-labs/dictum (Python analytics). Directly adjacent lane, crowded.
- **Parlang** - "parallel language" concept. Eliminated: exact-name programming-language repositories; too ambiguous for a product name.
- **Dilo** - Spanish imperative "say it" (di-lo). Eliminated: exact "DiLo" pronunciation/translation app on Google Play plus "Dilo en Señas" Mexican Sign Language app (Shark Tank Mexico). Exact lane collision.
- **Mova** - Ukrainian/Belarusian for "language." Eliminated: exact "MOVA: Belarusian language" app on Google Play (updated June 2026), plus multiple language-learning repos and design concepts under the name. Crowded.
- **Deixis** - Greek linguistic term for "pointing" words. Eliminated: multiple active exact-name GitHub repos - taoshi1999/deixis (AI interaction framework) and jolars/deixis (MCP server, updated days before this check).
- **Onomata** - Greek "names." Eliminated: reads as "onomatopoeia," a dead 2023 programming-language repo, and a 2013 vocabulary-teaching concept called "Onomat." Weak signal, no product strength.
- **Grammata** - Greek "letters." Eliminated: old exact-name programming-language repository; too close to "grammar" as a generic.
